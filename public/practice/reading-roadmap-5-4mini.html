0 0단계 · 가입 방법 안내

GitHub 가입 방법

  1. github.com 접속 후 Sign up 선택
  2. 이메일, 비밀번호, 사용자 이름 입력
  3. 이메일 인증 완료
  4. 강사 starter repo 접속
  5. Use this template → Create a new repository
  6. 저장소 이름 예: ppuppu-book-practice
  7. Windows Codex에서 내 repo 폴더를 열고 실습 시작
강사 repo에 직접 push하지 말고, 본인 계정에 복사한 repo에 push합니다.

Supabase 가입 방법

  1. supabase.com 접속 후 가입 또는 로그인
  2. New project 선택
  3. Project name, Database Password, Region 입력
  4. 프로젝트 생성 완료까지 대기
  5. Settings → Data API에서 Project URL 확인
  6. Settings → API Keys에서 Publishable key 복사
  7. Authentication에서 Anonymous Sign-in 켜기
Codex에 줄 값:
VITE_SUPABASE_URL=https://프로젝트ID.supabase.co
VITE_SUPABASE_ANON_KEY=Publishable key
/rest/v1/은 빼고, service_role / secret key / database password는 절대 사용하지 않습니다.

API 키가 필요 없는 Open Library Search API로 실제 도서 검색을 붙입니다. 검색 결과에서 책을 내 서재에 추가합니다.

/goal
책 검색 기능을 Open Library API와 연결해줘.

조건:
- 무료 플랜 실습이므로 작업 범위를 작게 유지
- API 키 없는 Open Library 사용
- 새 라이브러리 설치 금지
- Supabase는 하지 않음
- 기존 localStorage 저장 기능 유지
- npm run build는 마지막에 1번만 실행

API:
https://openlibrary.org/search.json?q=검색어&limit=10

기능:
1. 도서 검색 입력창과 검색 버튼 추가
2. 책 제목/작가명으로 API 검색
3. 결과 카드에 제목, 저자, 첫 출간 연도, ISBN, 표지 표시
4. cover_i가 있으면 https://covers.openlibrary.org/b/id/{cover_i}-M.jpg 사용
5. 결과 카드에 "내 서재에 추가" 버튼 추가
6. 추가한 책은 기존 책 목록과 localStorage에 저장
7. 검색 중, 결과 없음, 오류 상태 표시
8. 기존 기능은 망가뜨리지 않기

가능하면 API 코드는 src/lib/bookSearchApi.js로 분리해줘.
수정 후 변경 파일, 테스트 방법, build 결과를 알려줘.

3 3단계 · Supabase 연결 및 자료 저장

검색한 책과 직접 추가한 책을 Supabase DB에 저장합니다. 초보자용이므로 Codex가 .env.local도 만들게 합니다.

SQL Editor에 먼저 붙여넣을 SQL

create table if not exists public.books (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  title text not null,
  author text not null default '',
  status text not null default 'reading' check (status in ('reading', 'finished')),
  progress integer not null default 0 check (progress between 0 and 100),
  first_publish_year integer,
  isbn text,
  cover_url text,
  source text not null default 'manual',
  memo text,
  created_at timestamptz not null default now()
);

alter table public.books enable row level security;

drop policy if exists "Users can read own books" on public.books;
drop policy if exists "Users can insert own books" on public.books;
drop policy if exists "Users can update own books" on public.books;
drop policy if exists "Users can delete own books" on public.books;

create policy "Users can read own books"
on public.books
for select
to authenticated
using (auth.uid() = user_id);

create policy "Users can insert own books"
on public.books
for insert
to authenticated
with check (auth.uid() = user_id);

create policy "Users can update own books"
on public.books
for update
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

create policy "Users can delete own books"
on public.books
for delete
to authenticated
using (auth.uid() = user_id);
