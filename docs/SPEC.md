# Codex 바이브 하네스 교육 웹앱 SPEC

## 프로젝트 목적

첨부 PPTX `docs/source/codex_vibe_harness_교육자료.pptx`를 원본 기획자료로 삼아, 공무원 연수에서 발표자가 전체화면으로 사용할 수 있고 수강생이 이후 웹 교재처럼 다시 볼 수 있는 인터랙티브 HTML 강의 웹앱을 만든다.

이 작업은 PPT 변환이 아니라 React 기반 강의 웹앱 제작이다. 슬라이드, 용어집, 하네스 프롬프트 실습, 연수 질문·투표 보드, 보안 체크리스트를 하나의 로컬 앱으로 제공한다.

## 사용자

- 발표자: `/slide`에서 전체화면 발표, 키보드 조작, 발표자 노트 확인
- 수강생: `/study`에서 웹 교재 형태로 복습
- 실습자: `/prompt`, `/demo`에서 프롬프트 변환과 질문·투표 보드 체험

## 발표 모드

- 16:9 발표 화면에 최적화
- 슬라이드 넘김, 목차 패널, 발표자 노트, 에이전트 오케스트레이터 제공
- 키보드: ArrowRight, Space, ArrowLeft, F, M, N, D, Esc

## 학습 모드

- 전체 슬라이드를 챕터별 긴 글 형태로 제공
- 핵심 메시지, bullet, 발표자 노트 포함
- 모바일에서 세로형 웹 교재로 읽을 수 있게 구성

## 데모 모드

- 질문 등록
- 파일 첨부
- 공감 투표
- 답변 완료 체크
- 인기순/최신순 정렬
- CSV 다운로드
- localStorage 저장
- 더미 데이터 초기화

파일 첨부는 교육용 로컬 첨부로만 동작한다. 실제 서버 업로드는 하지 않으며, 파일 데이터는 브라우저 localStorage에 저장된다. 첨부 파일에도 실제 학생, 학부모, 교직원 개인정보를 넣지 않는다.

## 기능 요구사항

- React + TypeScript + Vite
- Tailwind CSS
- `motion` 기반 화면 전환 및 카드 등장 애니메이션
- `lucide-react` 아이콘
- `canvas-confetti` 완료 효과
- 외부 API Key와 실제 외부 연결 없음
- 오프라인 발표 환경에서도 핵심 기능 동작

## 보안 요구사항

이 강의 데모는 교육용이며 실제 학생, 학부모, 교직원 개인정보를 입력하지 않습니다. 외부 서비스 연결 전에는 기관 내부 규정, 계정 소유권, 보존기간, 요금, 장애 가능성을 반드시 확인해야 합니다.

- 예시 데이터는 더미 데이터만 사용
- API Key, Token, 비밀번호 저장 금지
- localStorage는 교육용 데모 저장소로만 사용
- 외부 서비스 연결은 설명용 애니메이션으로만 제공
