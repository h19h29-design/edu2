# DESIGN

## 디자인 콘셉트

첨부 이미지의 밝은 유리질 대시보드 느낌을 기준으로 한다. 전체 배경은 밝은 블루 톤이며, 카드에는 반투명 glassmorphism, 얇은 선, 부드러운 그림자, 네온 블루/퍼플 포인트를 사용한다.

터미널, diff, 보안 스캔 등 기술 장면은 어두운 패널을 섞어 "AI 개발 작업"의 대비를 만든다.

## 색상

- 배경: `#f9fcff`, `#eef7ff`
- 본문: `slate-900`
- 포인트: violet, blue, cyan
- 성공: emerald
- 경고: amber, rose
- 터미널: slate/black 계열

## 타이포그래피

- 시스템 sans-serif와 `Malgun Gothic`, `Apple SD Gothic Neo` 사용
- 발표장 가독성을 위해 제목은 굵게, 본문은 짧게
- 슬라이드 핵심 문장은 큰 카드로 분리

## 카드 스타일

- 주요 패널: `glass-card`
- 반경: 20px-34px
- 카드 내부에는 명확한 아이콘, 짧은 제목, 1-2문장 설명
- 발표 모드에서는 중첩 카드를 과도하게 쓰지 않고 핵심 흐름을 우선 표시

## 애니메이션 원칙

- 카드 등장, 진행바, 타이핑, 상태 변화 중심
- 발표자의 말을 방해하지 않도록 반복 애니메이션은 작고 느리게
- 3.5 슬라이드는 CLI와 Codex 작업공간 애니메이션을 길게 허용
- `prefers-reduced-motion` 환경에서는 애니메이션을 최소화

## 접근성

- 버튼은 텍스트와 아이콘을 함께 제공
- 모바일에서는 발표 제어 버튼 제공
- 입력창에는 placeholder와 개인정보 입력 금지 안내 제공
- 텍스트는 밝은 배경에서 충분한 대비를 유지

## 발표장 가독성 기준

- 슬라이드당 핵심 문장 1개를 크게 표시
- 상세 설명은 발표자 노트와 학습 모드로 이동
- 16:9 프레임 안에서 좌측 목차, 중앙 슬라이드, 우측 에이전트 상태가 한눈에 보이게 구성
