먼저 큰 그림

초보자는 “앱 설치”부터 시작하세요

Codex는 윈도우에서 크게 3가지 방식으로 쓸 수 있습니다. 처음이라면 Codex 앱이 가장 이해하기 쉽습니다.

🖥️

1순위: Codex 앱

프로그램처럼 설치하고 실행합니다. 여러 작업을 화면에서 확인하기 좋아 초보자에게 가장 적합합니다.

⌨️

2순위: CLI

PowerShell에 명령어를 붙여넣어 설치합니다. 터미널 사용이 가능하면 빠릅니다.

🧩

나중에: IDE 확장

VS Code, Cursor, Windsurf 같은 편집기 안에서 Codex를 쓰는 방식입니다.

이 자료는 앱 설치를 기본으로 설명하고, 뒤쪽에 CLI 설치 방법을 선택 사항으로 넣었습니다.
공식 문서: Windows에서 앱, CLI, IDE 확장 사용 가능02 / 18
준비물

설치 전에 딱 5가지만 준비합니다

윈도우 PC — 회사 보안 PC라면 설치 권한이 막혀 있을 수 있습니다.
인터넷 브라우저 — Edge 또는 Chrome을 열 수 있으면 됩니다.
ChatGPT 계정 — Codex 실행 후 로그인할 때 사용합니다.
작업 폴더 — 문서 폴더 아래에 Codex 전용 폴더를 만들 예정입니다.
10분 정도의 시간 — 설치보다 중요한 것은 안전한 폴더 선택입니다.
⚠️

중요: 처음부터 바탕화면, 다운로드 폴더, C드라이브 전체를 프로젝트로 열지 마세요. Codex가 작업할 범위를 작게 잡아야 안전합니다.

PowerShell을 열고 명령어를 붙여넣어 설치하는 방식입니다. 완전 초보자는 앱 설치를 먼저 성공한 뒤 진행하세요.

문제 해결

초보자가 가장 많이 막히는 지점

다운로드 버튼이 안 보여요

모바일이 아닌 PC 브라우저에서 공식 Codex 앱 페이지를 다시 열어보세요. 회사망에서는 차단될 수 있습니다.

로그인이 계속 반복돼요

기본 브라우저에서 ChatGPT 로그인을 먼저 완료한 뒤 Codex 앱을 다시 실행합니다.

PowerShell에서 스크립트가 막혀요

실행 정책 문제일 수 있습니다. 오류 메시지를 확인하고 필요한 경우 RemoteSigned 설정을 검토합니다.

Git 기능이 안 보여요

Windows에 Git이 설치되어 있지 않으면 일부 Git 기능이 안 될 수 있습니다. Git 설치 후 앱을 재시작합니다.

공식 근거

이 자료를 만든 기준

자료는 OpenAI 공식 Codex 문서 기준으로 구성했습니다. 실제 화면과 버튼 이름은 앱 업데이트에 따라 조금 달라질 수 있습니다.

2026-06-15 기준 확인

공식 문서 요약

• Codex 앱은 macOS와 Windows에서 제공되며, 다운로드 후 ChatGPT 계정 또는 API key로 로그인하고 프로젝트 폴더를 선택해 시작합니다.

• Windows에서는 Codex 앱, CLI, IDE 확장 방식을 사용할 수 있습니다.

• Windows 네이티브 실행 시 샌드박스는 작업 폴더 밖의 파일 쓰기를 막고, 네트워크 접근은 명시적 승인 없이는 제한하도록 설계되어 있습니다.

• CLI 설치가 필요하면 Windows PowerShell 설치 명령을 사용할 수 있습니다.

• Git이 없으면 Git 기능 일부가 동작하지 않을 수 있어 Windows에 Git 설치가 권장됩니다.
